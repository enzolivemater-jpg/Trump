Optional, but it is the only thing that fixes Reddit and Truth Social: neither sends CORS headers, and both refuse the shared public relays. A personal Cloudflare Worker is one origin, your own quota, and a real browser User-Agent set server-side — which is also what GDELT wants. Paste the worker URL ending in ?url=. Colour key · direction, status, sourcing
Transport. RSS no longer goes through generic CORS proxies. It goes through purpose-built RSS-to-JSON gateways that send CORS headers by design and stay up under load; the generic relays are kept only as a last resort. JSON APIs are called direct. The gateway that last worked for a feed is tried first next time, every response is shape-checked before acceptance, and a failing feed backs off exponentially instead of being hammered.

Nine feeds, not twenty. One broad wire query already returns dozens of outlets and GDELT returns thousands. Coverage comes from query breadth, not from feed count — and every extra request was buying rate limits, not variety.

Method. Dollar pressure and risk regime are sums over their window: each event signed by category, weighted by tier, scaled by implementation status (a threat counts half a signed order, a walked-back measure a third), decayed with age, clamped to ±1.00. Ambiguous categories contribute zero.
