Background & install
A web app cannot run freely in the background — the browser owns that decision. What is possible is registered here: an offline shell so a cold open paints instantly, cached feed responses, and periodic background sync. Android grants sync only to installed apps with real usage, and it fires on its own schedule. Treat it as a warm cache on open, not a live ticker.
Colour key · category
Colour key · direction, status & sourcing
Sources. Nine feeds across four families — global wire (GDELT, thousands of outlets), newswire aggregate, federal record, and social. Feeds with native CORS run in parallel; feeds that need a public relay run one at a time, spaced, because a burst gets the whole batch rate-limited.

Reading. Each headline is parsed on its own: rate, target country, sector, legal basis and implementation status are extracted from the text. A threat carries half the weight of a signed action. When nothing specific can be extracted, no commentary is shown rather than boilerplate.
